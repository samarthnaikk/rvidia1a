# Rvidia Hackathon

Project repository with separated services.

## Structure

- `frontend/` - React + Vite + Tailwind web app
- `backend/` - backend service
- `nginx/` - reverse proxy config
- `postgres/` - database setup

## Frontend local run

```bash
cd frontend
npm install
npm run dev
```

## Frontend build

```bash
cd frontend
npm run build
```
